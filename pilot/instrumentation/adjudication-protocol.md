# Adjudication protocol — unsupported assumptions and non-mechanical plants

**Status:** protocol only, frozen before runs. No adjudication has been performed.
**Scope:** the two measurements that no mechanical rule can settle — `unsupported_assumptions` in both
pilots, and the two adjudicated plants in `plants-H2.json` (H2-F3, H2-F4).

## 1. What the adjudicator receives

Per run, one packet generated by `tools/blind-packet.js`:

| Field | Why |
| --- | --- |
| `task` | the task statement the agent was given |
| `result` | files changed, files read, and the claims the agent made |
| `evidence_available` | the files and evidence that arm could reach |
| `gold` | impacted files, symbols, dependency edges, must-not-break |

**Removed:** arm, model, token counts, turn count, wall clock, oracle verdict, timestamps. The packet
generator redacts these and refuses to emit a packet that still contains one (`isBlind()`).

The adjudicator does not see the arm, the other arm, or any pilot result. Packets from both arms are
mixed and shuffled by packet id, so consecutive packets are not the same arm.

## 2. What is being judged

Only this question, per claim:

> Could an agent with the evidence listed in `evidence_available` have supported this claim?

Four outcomes, and the distinction is the point:

| Outcome | Meaning |
| --- | --- |
| **supported** | the claim follows from evidence the agent could see |
| **reasonable_but_wrong** | the agent could reasonably have believed it from that evidence, but it is false — a wrong inference, not an unsupported assertion |
| **unsupported** | the evidence available does not support the claim; the agent asserted something it could not have known from what it had |
| **indeterminate** | the packet does not contain enough to decide |

**Only `unsupported` counts toward P4 / Q5.** `reasonable_but_wrong` is counted and reported
separately: it is a quality signal, not a fabrication signal, and folding the two together would
punish an agent for a defensible inference that happened to be incorrect.

`indeterminate` is never silently counted as pass or fail. It is reported, and a run with more than
two indeterminate claims is flagged for re-adjudication rather than scored.

## 3. Procedure

1. Packets are generated for all runs before any is judged, so no judgement is informed by a partial
   view of the distribution.
2. Each packet is judged by one reviewer. A second reviewer judges a **20% random sample**, drawn by
   packet id, without seeing the first judgement.
3. Agreement is reported as raw agreement on the `unsupported` / not-`unsupported` split. Below 0.80
   the whole set is re-adjudicated by a third pass and the disagreement is reported, not resolved by
   majority.
4. Judgements are recorded as `{packet_id, claim_index, outcome, one_line_reason}`. The reason is
   required; a judgement without a reason is not a judgement.
5. Arm identity is re-attached only after all judgements for a task are complete.

## 4. Who may adjudicate

Someone who has not authored the fixtures, the gold sets, or the patches for that task — and who has
not seen the run logs. If no such person is available, the measurement is reported as
**self-adjudicated** and no pass criterion that depends on it may be claimed.

That is a hard rule, not a preference: an author judging their own fixture is measuring their own
expectation.

## 5. Recording

`pilot/adjudication/` holds the packets, the judgement file and a `summary.json` with per-outcome
counts per packet. The pilot results document must state the reviewer's independence status, the
sample size for the second review, and the agreement rate.

## 6. What this protocol does not fix

- It cannot make a small sample reliable. Ten packets per cell judged by one person is still ten
  judgements.
- It does not validate the gold sets, only the claims against them.
- It cannot detect a claim that is unsupported but so obviously true that the reviewer marks it
  supported. The mechanical evidence-reference check remains the primary signal; adjudication resolves
  the cases where a citation exists but does not entail the claim.
